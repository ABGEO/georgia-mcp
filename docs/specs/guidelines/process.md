# Process

The narrative guide is `docs/specs/README.md`. This file holds the binding rules.

## PRC-001

Every change to the behavior that a client of the server can see starts with a
requirement statement. The requirement comes before the specification. The
specification comes before the code.

**Why:** The code is a result. The intent must exist in a document that a person
can read.

## PRC-002

A technology choice needs a requirement that demands it.
Do not add a technology to the guidelines before the requirement exists.

## PRC-003

Every document obeys `LNG`. Every identifier obeys `TRC`.
